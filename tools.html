    Reading the output

    How to use these numbers.

    A calculator assumes one steady rate every year. Markets never deliver that. Treat each result as a planning range, not a prediction.

    1. 01

      Run three scenarios

      Try a cautious, a middle and a hopeful return rate. If the plan only works at the hopeful rate, the plan needs more time or a larger instalment.

    2. 02

      Think in today's rupees

      ₹1 crore in 20 years will buy far less than ₹1 crore today. The goal planner inflates your target first, so the SIP it suggests is sized for future prices.

    3. 03

      Order of returns matters

      Two portfolios with the same CAGR can end in different places if one meets a crash near the finish. Real paths are bumpy; the charts here are smoothed.

    4. 04

      Costs and taxes come off the top

      These figures are before brokerage, fund expenses and capital-gains tax. Subtract them before you compare options or set a target.
